# 🚌 Bus Reservation System (Java Console Application)

## 📌 Overview

This is a simple **Bus Reservation System** built using **Core Java**.  
The application runs in the console and allows users to:

- View available buses
- Book tickets by entering name, bus number, and travel date
- Check seat availability based on bus capacity
- Prevent overbooking for the same bus on the same date

It demonstrates basic Object-Oriented Programming concepts such as:

- Classes & Objects  
- Constructors  
- Encapsulation  
- ArrayList usage  
- Date parsing  
- User input handling  

---

## ✨ Features

✅ Display bus details (Bus No, AC, Capacity)  
✅ Book tickets interactively  
✅ Date-based booking  
✅ Capacity validation (no overbooking)  
✅ Simple user-friendly console interface  

---

## 🛠 Technologies Used

- Java  
- OOP Concepts  
- Collections (`ArrayList`)  
- `Scanner` for user input  
- `SimpleDateFormat` for date handling
