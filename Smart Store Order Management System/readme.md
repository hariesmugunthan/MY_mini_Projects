ShopFlow — Smart Store Order Management System

ShopFlow is a console-based Java application built with Core Java, JDBC, MySQL, and OOP, designed to support different types of shops such as grocery stores, dairy shops, stationery stores, mini marts, and retail outlets. It manages the complete order process — from customer handling and product management to billing and order storage through database integration.

The system is flexible and can be adapted for any small or medium shop that needs a simple digital solution for daily sales operations.

🚀 Tech Stack
  ☕ Java
  🔌 JDBC
  🗄 MySQL
  🧩 OOP
  💻 IntelliJ IDEA

✨ Features

  👤 New / Existing Customer Management
  📦 Product Add / View Management
  🛒 Multi-Product Order Placement
  🔁 Quantity Update for Repeated Items
  💰 Automatic Bill Calculation
  🧾 Order Record Storage
  📊 Console Table-Based UI
  🔒 Secure Queries using PreparedStatement 

🎯 Why ShopFlow?

ShopFlow was developed to apply Java OOP and JDBC concepts in a real-world business environment.
It demonstrates how software can simplify sales, customer handling, and billing operations for different kinds of retail shops.
